# سیستم پیشنهاددهنده فیلم (Movie Recommender System)

## ۱. تعریف مسئله
هدف این پروژه، طراحی یک عامل هوشمند (Agent) است که با تحلیل تاریخچه تعاملات کاربر (مانند امتیازدهی، تماشا و جستجو) و ویژگی‌های فیلم‌ها (مانند ژانر و کارگردان)، مناسب‌ترین فیلم‌ها را به هر کاربر پیشنهاد می‌دهد.

## ۲. مؤلفه‌های PEAS

| مؤلفه | توضیحات |
| :--- | :--- |
| **P (معیار عملکرد)** | دقت پیشنهادها (Precision@K)، رضایت کاربر، تنوع در پیشنهادها (Diversity)، سرعت پاسخ‌دهی سیستم. |
| **E (محیط)** | کاربران، پایگاه داده فیلم‌ها، تاریخچه تعاملات، و رابط کاربری (وب یا اپلیکیشن). |
| **A (عملگرها)** | نمایش لیست پیشنهادها به کاربر، ذخیره بازخورد (Like/Dislike)، و به‌روزرسانی پروفایل کاربر. |
| **S (حسگرها)** | ثبت کلیک‌ها، دریافت امتیازها (Rating)، تاریخچه تماشا، و زمان صرف‌شده برای هر فیلم. |

## ۳. شش ویژگی محیط پروژه

| ویژگی (Property) | وضعیت | توضیح کوتاه |
| :--- | :--- | :--- |
| **قابل مشاهده بودن** (Observability) | **Partially Observable** | سیستم فقط بخشی از ترجیحات کاربر را از طریق تعاملاتش می‌بیند و علایق پنهان زیادی وجود دارد. |
| **قطعیت** (Determinism) | **Stochastic** | رفتار کاربر و انتخاب‌های او غیرقابل پیش‌بینی و تصادفی است. |
| **اپیزودیک یا ترتیبی** (Episodic/Sequential) | **Sequential** | هر پیشنهاد سیستم، بر روی رفتار بعدی کاربر تأثیر می‌گذارد و تصمیم‌ها زنجیره‌ای هستند. |
| **ایستا یا پویا** (Static/Dynamic) | **Dynamic** | سلیقه کاربران، کاتالوگ فیلم‌ها و امتیازها مدام در حال تغییر هستند. |
| **گسسته یا پیوسته** (Discrete/Continuous) | **Discrete** | آیتم‌ها (فیلم‌ها) و امتیازهای داده‌شده (مثلاً ۱ تا ۵) حالت گسسته دارند. |
| **تک‌عاملی یا چندعاملی** (Single/Multi-agent) | **Multi-agent** | کاربران متعدد و سیستم پیشنهاددهنده به صورت تعاملی با هم در ارتباط هستند. |
